# GHOST//NET

A fictional cyber-operations dashboard built as an interactive visual demo.

## Safety
This project does **not** perform real network scanning, tracing, credential collection, exploitation, malware delivery, or external system access. All nodes, missions, logs, decryptions, and terminal commands are simulated in the browser.

## Files
- `index.html` — layout
- `style.css` — visual theme and animations
- `script.js` — harmless simulated interactions

Open `index.html` locally or publish the folder on a static host.
